# Faith Journal (Starter App)

A lightweight starter web app for Christians to build daily habits around prayer, gratitude, and Scripture reflection.

## MVP Features

- **Daily Verse Prompt**: Displays one rotating verse each day from a small built-in set.
- **Prayer List**: Add and remove prayer requests.
- **Gratitude Journal**: Write a short gratitude note and save it locally.
- **Reflection Prompt**: Encourages personal reflection each day.

## Tech

- Plain HTML, CSS, JavaScript
- LocalStorage for persistence (no backend yet)

## Run Locally

```bash
python3 -m http.server 4173
```

Then open: `http://localhost:4173`
